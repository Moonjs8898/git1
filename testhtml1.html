2. 장비 개요

웨이퍼 표면에 얇은 막을 입히는 공정 장비이다. 작업자가 MES 화면에서 작업을 시작하면 MCS가 캐리어를 장비로 옮기고, 장비가 도착을 보고하면 MES가 진행 가능 여부를 검증한 뒤 EIS를 통해 장비에 레시피와 시작을 지시한다.

공정 중에는 온도·압력·가스 유량을 이벤트로 보고받아 기준을 벗어나면 로트를 Hold 한다. 공정이 끝나면 Track Out 후 MCS에 반출을 요청한다.

이 문서의 값(이벤트 번호, 테이블 이름, 기준값 등)은 모두 예시입니다. 실제 사양서와 DB 구조로 바꿔 주세요.

3.3 단계별 상세

1작업 시작 (반송 요청)

작업자가 MES 작업 화면에서 로트와 장비를 골라 작업을 시작한다. MES는 로트·장비 상태를 확인하고 장비를 예약한 뒤 MCS에 반송을 요청한다.

메시지보내는 곳 → 받는 곳주요 항목
WorkStartReqUI → MESLotID, EqpID, UserID
TransferReqMES → MCSCarrierID, From, Dest(CVD-01/LP1)

2캐리어 도착

캐리어가 포트에 올라오면 장비가 도착 이벤트를 보내고, EIS가 이를 사내 메시지로 바꿔 MES에 전달한다. MCS도 반송 완료를 따로 알린다.

메시지보내는 곳 → 받는 곳주요 항목예시
S6F11 CEID 100장비 → EISCarrierID, PortIDCR-00123, LP1
CarrierArrivedEIS → MESEqpID, CarrierID, PortIDCVD-01, CR-00123, LP1
TransferCompletedMCS → MESCarrierID, Loc, ResultCodeCR-00123, CVD-01/LP1, 0

3Track In 검증

MES가 로트·레시피·장비 상태를 확인한다. 하나라도 맞지 않으면 Track In 을 거부한다.

검증 항목기준조회 테이블
로트 상태WAIT 상태, Hold 아님LOT
레시피공정 단계 지정 레시피 = 장비 등록 레시피RECIPE
장비 상태IDLE 상태, PM 주기 이내EQP

관련 인터락: IL-CVD-01 레시피 불일치, IL-CVD-02 PM 주기 초과

6공정 시작

MES가 시작을 지시하고, 장비의 시작 보고를 받으면 로트와 장비 상태를 RUN 으로 바꾼다.

메시지보내는 곳 → 받는 곳주요 항목

S2F41 STARTEIS → 장비LotID

공정 단계마다 주요 값을 보고한다. MES는 값을 저장하고 관리 범위를 벗어나면 인터락을 건다.

메시지보내는 곳 → 받는 곳주요 항목예시

MES가 로트를 다음 공정 단계로 넘기고, 처리 매수를 장비 PM 카운트에 더한다. 변경되는 테이블은 3.2 테이블 상태 변경 요약 참고.

5. 특이 사항

  • LP2 포트는 더미 웨이퍼 전용으로 운영 (예시)
  • EIS와 장비 통신이 끊기면 MES는 5분 후 EQP.STATE 를 COMM_OFF 로 바꾸고 신규 Track In 을 막는다.
  • Track In · Track Out 자동/수동 설정은 장비별 설정값을 따른다.
